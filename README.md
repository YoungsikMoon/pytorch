# PyTorch · 모델 학습 흐름 실습

텐서 연산부터 데이터 로딩·학습·평가·모델 저장까지 이어지는 PyTorch 학습 기록입니다. 기본 예제와 문영식의 개·고양이 이미지 분류 실습을 함께 보관합니다.

## 살펴볼 노트북

- [기본 실습](pytorch_all.ipynb): 텐서, 자동 미분, DataLoader, 손실 함수·옵티마이저, 모델 학습과 저장
- [참고 풀이](pytorch_all%28solution%29.ipynb): 학습용 제공 풀이
- [개·고양이 분류 — 문영식](%EA%B0%9C_%EA%B3%A0%EC%96%91%EC%9D%B4_%EB%B6%84%EB%A5%98_%EB%AC%B8%EC%98%81%EC%8B%9D.ipynb): 사용자 정의 데이터셋, 이미지 확인·증강, 사전학습 ResNet101을 활용한 분류 실습

## 실행 안내

Jupyter 또는 Colab에서 셀의 설치·데이터 경로 설정부터 확인합니다. 이미지 데이터와 사전학습 가중치, 사용 가능한 CPU/GPU에 따라 설정이 달라집니다. 노트북 출력의 수치는 해당 실행의 기록이며 독립적으로 검증한 성능 보장은 아닙니다.

참고 풀이와 직접 작성한 실습을 구분하며, 학습 자료 전체를 독자 구현물로 주장하지 않습니다.
